# 紹介特典アプリ（智翔館 中等部）

Google フォーム＋スプレッドシート（【中等部】紹介特典（回答））で運用していた友人紹介特典を Web アプリにしたものです。

- **保護者向け申込フォーム** `/apply` … カードの QR コードから開き、招待コードと連絡先を入力（Google フォーム「紹介特典」の置き換え）
- **職員向け管理画面** `/admin` … 特典コードの登録、生徒の割り当て、入塾・入金・Amazon 発注・送付の進捗管理（「管理表」「職員入力データ」の置き換え）

## 業務の流れ（運用マニュアル準拠）

「中等部 紹介特典制度 運用マニュアル（修正版）」の STEP に沿って動きます。

| STEP | 作業 | アプリでの操作 | 状態 |
|------|------|--------------|------|
| 準備 | カードを印刷して校舎へ配布 | コード登録で連番をまとめて登録（校舎配布日） | 未割当 |
| 1〜2 | 塾生へ紹介依頼 → 入塾・講習申込み | ― | |
| 3 | 職員が特典管理へ入力（**STEP2 から3日以内**） | コードを開き「紹介してくれた塾生」「紹介された生徒」「区分」「入塾日・講習申込日」を入力 | 申込待ち |
| 4 | 塾生へカードを渡す | 「カード配布日」を入力（保護者の入力期限の起点） | 申込待ち |
| 5 | 保護者が QR から入力（**カード配布から1か月以内**） | `/apply?code=…` から送信 | 入塾・入金待ち |
| ― | 入金確認 → Amazon 発注 → 送付 | 入金日・発注日・ギフトコード・送付日を入力 | 発注待ち → 送付待ち → 送付完了 |

### ルールのチェック

- **外部生1名につき特典は1回のみ**（マニュアル３・７）
  STEP3 で「紹介された生徒」を入力すると、過去のコードに同じ外部生（空白・「﨑/崎」「髙/高」の違いは同一視）がいないか確認し、いれば該当コードを表示して登録を止めます。
  同姓同名の別人の場合のみ「別人であることを確認した」にチェックして登録できます。
- **STEP3 の必須項目**：塾生を入力する場合、「紹介された生徒」と「区分（通常入会／講習会申込み）」は必須です。
- **職員入力の3日期限**：入塾日・講習申込日から3日を過ぎて入力された（またはまだ入力されていない）コードに「入力3日超過」を表示します。
- **保護者入力の1か月期限**（マニュアル５）：カード配布日から1か月を過ぎた入力は
  - 無効（特典対象外）として記録し、管理画面に **「期限終了後申請」** と表示
  - 保護者には期限切れの画面を表示し、**自動メールで期限切れを通知**
  - 申込みがないまま期限を過ぎたコードは状態が「期限切れ」になります
  - 特別な事情がある場合は、校舎責任者・NEP 相談の上、コード詳細で理由を入力して「特例として有効にする」と通常の流れに戻せます
- 一覧上部の「要対応」（期限終了後申請・職員入力3日超過・外部生の重複疑い）をクリックすると該当コードだけに絞り込めます。

### その他

- 一覧上部の件数タイルをクリックすると、その状態のコードだけに絞り込めます。
- 保護者が入力した「紹介した方」「生徒名」が職員入力と一致しない場合は「⚠ 要確認」と表示します。
- 同じコードに複数回申込みがあった場合は件数を表示し、詳細画面で最新の申込みに「最新」ラベルが付きます。
- 「CSV出力」で、一覧の絞り込み条件のまま Excel で開ける CSV をダウンロードできます。

## 技術構成

- Next.js 16（App Router / Server Actions）+ TypeScript + Tailwind CSS 4
- nodemailer（期限切れ通知メール）
- Prisma 6（開発: SQLite、本番: PostgreSQL 推奨）
- zod（入力チェック）、Vitest（テスト）
- 職員ログインは共通パスワード＋署名付き Cookie（12時間）

## セットアップ

```bash
npm install
cp .env.example .env        # ADMIN_PASSWORD と SESSION_SECRET を必ず変更
npx prisma migrate dev      # DB 作成
npm run db:seed             # 校舎（日野校・日宇校・大野校・佐々校）を登録
npm run dev                 # http://localhost:3000
```

- 保護者フォーム: http://localhost:3000/apply
- 管理画面: http://localhost:3000/admin （`.env` の `ADMIN_PASSWORD` でログイン）

### 環境変数

| 変数 | 説明 |
|------|------|
| `DATABASE_URL` | DB 接続先。SQLite なら `file:./dev.db` |
| `ADMIN_PASSWORD` | 職員用ログインパスワード |
| `SESSION_SECRET` | セッション署名用の秘密鍵（16文字以上のランダム文字列。`openssl rand -base64 32` など） |
| `APP_URL` | 任意。公開 URL（コード詳細に表示する QR 用 URL に使用） |
| `SMTP_HOST` `SMTP_PORT` `SMTP_USER` `SMTP_PASS` `MAIL_FROM` | 期限切れ通知メールの送信設定。Gmail なら `smtp.gmail.com` / `465` / アドレス / アプリパスワード。未設定の場合は送信せずサーバーログに出力し、コード詳細から後で送信できます |

## 本番運用

1. PostgreSQL を用意し、`prisma/schema.prisma` の `provider` を `"postgresql"` に変更します。
   マイグレーションは SQLite 用に作成しているため、`prisma/migrations` を削除して `npx prisma migrate dev --name init` で作り直してください。
2. ホスティング（Vercel 等）に環境変数を設定し、デプロイ時に `npm run db:deploy` を実行します。
3. 初回のみ `npm run db:seed` で校舎を登録します（管理画面の「校舎」からも追加・非表示にできます）。

### QR コード

カードの QR コードは `https://<公開URL>/apply?code=<招待コード>` を指すようにすると、招待コードと所属校舎が入力済みの状態でフォームが開きます。
コードを含めない `https://<公開URL>/apply` でも利用できます（保護者がコードを手入力）。

## スプレッドシートからの移行

「管理表」シートを **ファイル > ダウンロード > カンマ区切り形式（.csv）** で書き出し、取り込みます。

```bash
npm run import:sheet -- 管理表.csv --dry-run   # 件数だけ確認
npm run import:sheet -- 管理表.csv
```

- 見出し行（「校舎名」を含む行）から列を自動で判定します。「2025管理表」「2024年度管理表」など列の並びが違うシートも取り込めます。
- 登録済みのコードはスキップするので、複数シートを順に取り込んで構いません。
- 「Amazon発注済み」が TRUE の行は、メール送信日時を発注日・送付日として取り込みます。
- 管理表にはカード配布日・職員入力日時がないため、取り込んだコードには1か月期限・3日期限の判定をかけません（職員入力日時は入塾日とみなします）。
- 見出しのない列（「7/2校舎配布」「11/6入塾」などのメモ）は備考にまとめます。
- スプレッドシートで先頭の 0 が落ちた電話番号（`9036607242` など）は補って取り込みます。

> CSV には保護者の個人情報が含まれます。リポジトリにはコミットしないでください。
