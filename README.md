# 紹介特典アプリ（智翔館 中等部）

Google フォーム＋スプレッドシート（【中等部】紹介特典（回答））で運用していた友人紹介特典を Web アプリにしたものです。

- **保護者向け申込フォーム** `/apply` … カードの QR コードから開き、招待コードと連絡先を入力（Google フォーム「紹介特典」の置き換え）
- **経理用 管理画面** `/admin` … 特典コードの登録、内容確認・入力・修正、入金・Amazon 発注・送付、備考、特例承認、CSV 出力（「管理表」の置き換え）
- **校舎担当者用 状況確認画面** `/campus` … 自校舎の状況とエラー（要対応・申込みエラー）の確認、STEP3・4 の入力（「職員入力フォーム」「エラー通知メール」の置き換え）

ログインは `/login`。担当（経理／各校舎）を選んでパスワードを入力します。

## 画面と権限

| 操作 | 経理 `/admin` | 校舎担当者 `/campus` |
|------|:---:|:---:|
| 閲覧できる範囲 | 全校舎 | 自校舎のみ |
| 状況（状態別件数）・要対応（エラー）の確認 | ○ | ○ |
| 申込みエラー（招待コード誤り等で送信できなかった申込み）の確認・対応済み | ○ | ○ |
| STEP3（紹介してくれた塾生・紹介された生徒・区分）・STEP4（カード配布日）の入力 | ○ | ○（特典送付後は不可） |
| 保護者申込みの内容確認（確認済みにする）・削除 | ○ | 閲覧のみ |
| 入金日・Amazon 発注日・ギフトコード・送付日の入力 | ○ | 閲覧のみ（ギフトコードは非表示） |
| 備考の入力 | ○ | 閲覧のみ |
| 期限終了後申請の特例承認・期限切れ通知メールの送信 | ○ | ― |
| コード登録・コード番号や校舎の修正・削除 | ○ | ― |
| CSV 出力、校舎の追加とパスワード設定 | ○ | ― |

- 経理のパスワードは環境変数 `ADMIN_PASSWORD`。
- 校舎担当者のパスワードは経理画面の「校舎・パスワード」で校舎ごとに設定します（8文字以上、DB にはハッシュで保存）。未設定の校舎はログインできません。

### 要対応（エラー）の種類

| 表示 | 内容 |
|------|------|
| 期限終了後申請（未承認） | カード配布から1か月を過ぎて保護者が入力した。特例にするかは校舎責任者・NEP と相談 |
| 期限切れ通知メール未送信 | 期限切れの通知メールが送れていない（GAS 未設定・送信失敗） |
| 入力期限7日以内・未申込 | 保護者の入力期限が近い。保護者へ声かけ |
| 職員未入力のコードへ申込 | 保護者の申込みはあるが STEP3 が未入力 |
| 職員入力が3日超過 | 入塾・講習申込日から3日を過ぎて STEP3 を入力（または未入力） |
| 保護者入力と職員入力の不一致 | 保護者が入力した生徒名・紹介した方が職員入力と一致しない |
| 外部生の重複疑い | 同じ外部生が別のコードで特典対象になっている |
| 申込みエラー | 招待コードが見つからない・特典送付済みのコードで、保護者が送信できなかった |

## 業務の流れ（運用マニュアル準拠）

「中等部 紹介特典制度 運用マニュアル（修正版）」の STEP に沿って動きます。

| STEP | 作業 | アプリでの操作 | 状態 |
|------|------|--------------|------|
| 準備 | カードを印刷して校舎へ配布 | コード登録で連番をまとめて登録（校舎配布日） | 未割当 |
| 1〜2 | 塾生へ紹介依頼 → 入塾・講習申込み | ― | |
| 3 | 職員が特典管理へ入力（**STEP2 から3日以内**） | コードを開き「紹介してくれた塾生」「紹介された生徒」「区分」「入塾日・講習申込日」を入力 | 申込待ち |
| 4 | 塾生へカードを渡す | 「カード配布日」を入力（保護者の入力期限の起点） | 申込待ち |
| 5 | 保護者が QR から入力（**カード配布から1か月以内**） | `/apply?code=…` から送信 | 入塾・入金待ち |
| ― | 入金確認 → Amazon 発注 → 送付 | 入金日・発注日・ギフトコード・送付日を入力 | 発注待ち → 送付待ち → 送付完了 |

### ルールのチェック

- **外部生1名につき特典は1回のみ**（マニュアル３・７）
  STEP3 で「紹介された生徒」を入力すると、過去のコードに同じ外部生（空白・「﨑/崎」「髙/高」の違いは同一視）がいないか確認し、いれば該当コードを表示して登録を止めます。
  同姓同名の別人の場合のみ「別人であることを確認した」にチェックして登録できます。
- **STEP3 の必須項目**：塾生を入力する場合、「紹介された生徒」と「区分（通常入会／講習会申込み）」は必須です。
- **職員入力の3日期限**：入塾日・講習申込日から3日を過ぎて入力された（またはまだ入力されていない）コードに「入力3日超過」を表示します。
- **保護者入力の1か月期限**（マニュアル５）：カード配布日から1か月を過ぎた入力は
  - 無効（特典対象外）として記録し、管理画面に **「期限終了後申請」** と表示
  - 保護者には期限切れの画面を表示し、**自動メールで期限切れを通知**
  - 申込みがないまま期限を過ぎたコードは状態が「期限切れ」になります
  - 特別な事情がある場合は、校舎責任者・NEP 相談の上、コード詳細で理由を入力して「特例として有効にする」と通常の流れに戻せます
- 一覧上部の「要対応」（期限終了後申請・職員入力3日超過・外部生の重複疑い）をクリックすると該当コードだけに絞り込めます。

### その他

- 一覧上部の件数タイルをクリックすると、その状態のコードだけに絞り込めます。
- 保護者が入力した「紹介した方」「生徒名」が職員入力と一致しない場合は「⚠ 要確認」と表示します。
- 同じコードに複数回申込みがあった場合は件数を表示し、詳細画面で最新の申込みに「最新」ラベルが付きます。
- 「CSV出力」で、一覧の絞り込み条件のまま Excel で開ける CSV をダウンロードできます。

## 技術構成

- Next.js 16（App Router / Server Actions）+ TypeScript + Tailwind CSS 4
- Prisma 6 + **Supabase（PostgreSQL）**
- 通知メール: **Google Apps Script（GAS）の Web アプリ経由で社用 Gmail から送信**（スクリプトは [`gas/`](gas/README.md)）
- zod（入力チェック）、Vitest（テスト）
- ログインは経理（環境変数のパスワード）と校舎担当者（校舎ごとのパスワード・scrypt ハッシュ）の2種類。署名付き Cookie（12時間）に役割と校舎を保持

## 開発環境のセットアップ

ローカルの PostgreSQL（または開発用の Supabase プロジェクト）を用意します。

```bash
npm install
cp .env.example .env        # DATABASE_URL / DIRECT_URL と ADMIN_PASSWORD・SESSION_SECRET を設定
npx prisma migrate dev      # テーブル作成
npm run db:seed             # 校舎（日野校・日宇校・大野校・佐々校）を登録
npm run dev                 # http://localhost:3000
```

- 保護者フォーム: http://localhost:3000/apply
- ログイン: http://localhost:3000/login （経理は `.env` の `ADMIN_PASSWORD`。校舎担当者は経理画面で校舎パスワードを設定してから）
- `GAS_MAIL_URL` を設定しない場合、メールは送信されずサーバーログに内容が出力されます。

### 環境変数

| 変数 | 必須 | 説明 |
|------|:---:|------|
| `DATABASE_URL` | ○ | アプリ用の DB 接続。Supabase の **Transaction pooler**（ポート 6543）に `?pgbouncer=true&connection_limit=1` を付けたもの |
| `DIRECT_URL` | ○ | マイグレーション用の DB 接続。Supabase の **Session pooler** または **Direct connection**（ポート 5432） |
| `ADMIN_PASSWORD` | ○ | 経理用ログインパスワード（校舎担当者のパスワードは管理画面で設定） |
| `SESSION_SECRET` | ○ | セッション署名用の秘密鍵（32文字以上のランダム文字列。`openssl rand -base64 32` など） |
| `APP_URL` | 推奨 | 公開 URL（コード詳細に表示する QR 用 URL に使用） |
| `GAS_MAIL_URL` | 推奨 | 通知メール送信用 GAS Web アプリの URL（`https://script.google.com/macros/s/.../exec`） |
| `GAS_MAIL_SECRET` | 推奨 | GAS のスクリプト プロパティ `MAIL_SECRET` と同じ合言葉 |

### QR コード

カードの QR コードは `https://<公開URL>/apply?code=<招待コード>` を指すようにすると、招待コードと所属校舎が入力済みの状態でフォームが開きます。
コードを含めない `https://<公開URL>/apply` でも利用できます（保護者がコードを手入力）。

## スプレッドシートからの移行

「管理表」シートを **ファイル > ダウンロード > カンマ区切り形式（.csv）** で書き出し、取り込みます。

```bash
npm run import:sheet -- 管理表.csv --dry-run   # 件数だけ確認
npm run import:sheet -- 管理表.csv
```

- 見出し行（「校舎名」を含む行）から列を自動で判定します。「2025管理表」「2024年度管理表」など列の並びが違うシートも取り込めます。
- 登録済みのコードはスキップするので、複数シートを順に取り込んで構いません。
- 「Amazon発注済み」が TRUE の行は、メール送信日時を発注日・送付日として取り込みます。
- 管理表にはカード配布日・職員入力日時がないため、取り込んだコードには1か月期限・3日期限の判定をかけません（職員入力日時は入塾日とみなします）。
- 見出しのない列（「7/2校舎配布」「11/6入塾」などのメモ）は備考にまとめます。
- スプレッドシートで先頭の 0 が落ちた電話番号（`9036607242` など）は補って取り込みます。

> CSV には保護者の個人情報が含まれます。リポジトリにはコミットしないでください。
