# 通知メール送信用 GAS の設定

アプリの期限切れ通知メールは、この GAS（Google Apps Script）を通して社用 Gmail から送信します。

## 1. スクリプトを作る

1. 送信元にしたい**社用 Gmail のアカウント**で https://script.google.com を開き、「新しいプロジェクト」を作成
2. プロジェクト名を「紹介特典メール送信」などに変更
3. `コード.gs` の中身をすべて消し、このフォルダの `Code.gs` を貼り付けて保存

## 2. 合言葉（シークレット）を設定する

1. ランダムな長い文字列を1つ用意（例: `openssl rand -base64 32` の出力）
2. 左メニュー「プロジェクトの設定」→「スクリプト プロパティ」→「スクリプト プロパティを追加」

| プロパティ | 値 |
|-----------|----|
| `MAIL_SECRET` | 用意した文字列（アプリの `GAS_MAIL_SECRET` と同じ値） |
| `SENDER_NAME` | 差出人名（任意。例: `智翔館`） |
| `REPLY_TO` | 返信先アドレス（任意。例: 問い合わせ用アドレス） |

## 3. 権限を承認する（初回のみ）

エディタ上部の関数選択で `testSend` を選んで「実行」→ Gmail 送信の権限を承認します。
自分宛てにテストメールが届けば OK です。

## 4. Web アプリとしてデプロイする

1. 右上「デプロイ」→「新しいデプロイ」→ 種類の選択で「ウェブアプリ」
2. 設定
   - 次のユーザーとして実行: **自分**（社用 Gmail アカウント）
   - アクセスできるユーザー: **全員**
     （アプリのサーバーから呼び出すため。合言葉が一致しないリクエストは送信されません）
3. 「デプロイ」→ 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）をコピー

## 5. アプリに設定する

アプリのホスティング先の環境変数に設定します。

| 変数 | 値 |
|------|----|
| `GAS_MAIL_URL` | 手順4の URL |
| `GAS_MAIL_SECRET` | 手順2の `MAIL_SECRET` と同じ値 |

## 注意

- `Code.gs` を修正したときは「デプロイ」→「デプロイを管理」→ 編集 →「バージョン: 新バージョン」で更新してください（URL は変わりません）。「新しいデプロイ」にすると URL が変わります。
- Gmail の送信数上限は Google Workspace で1日約1,500通です（本アプリの用途では十分です）。
- 送信に失敗した場合、アプリの管理画面に「期限切れ通知メール未送信」と表示され、コード詳細から再送できます。
